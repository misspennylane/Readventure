# 📚 Readventure – A Personal Book Tracking App

_Readventure_ is a personal book tracker built with Angular. It helps you manage your reading list, keep notes, and rate books — all in one sleek app.

## 🚀 Features

- ✅ Add books to your reading list
- ✅ Track reading status: To Read, Reading, Finished
- ✅ Rate and review books
- ✅ See all your books in a single overview
- ✅ Store your data locally (no login required)

Planned:
- 📊 Reading statistics
- 🎨 Dark mode toggle
- 🔍 Search & sort
- 🖼️ Book cover images

## 🧠 Why I Built This

As part of my frontend development learning journey, I wanted to build a real-world Angular app with routing, forms, state management, and a clean UI. Readventure is the result — a project that grows with my skills and my bookshelf.

## 🛠️ Tech Stack

- [Angular 19](https://angular.io/)
- [TypeScript](https://www.typescriptlang.org/)
- [Angular Material](https://material.angular.io/)
- SCSS
- LocalStorage for persistence
